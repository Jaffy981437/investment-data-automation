## 零、先講三個關鍵結論

### 1. 方舟運算是**手機 APP**,不是桌面軟體,也沒有 API

黑色 ARK 圖示的 Android / iOS APP。Windows 使用者的做法是**裝 MuMuPlayer 安卓模擬器**,在模擬器裡安裝方舟運算,再用 AI 的「Computer Use」控制滑鼠鍵盤去點 APP 介面。

**沒有任何官方 API 或匯出功能。**資料進出只能靠 GUI 操作,或截圖給 AI 判讀。

### 2. 資料流方向和直覺相反 —— 方舟是「輸入端」,不是資料來源

社群整套自動化在做的事是:

```
券商 APP(樹精靈 / 國泰 / 台新…)
   │  ← 庫存與成本的真正來源
   ├─ 台股:操作樹精靈匯出成 csv
   └─ 美股:截圖給 AI 判讀
                    ↓
            方舟運算 APP(手動逐檔 key in)
                    ↓
        方舟算出「布局 / 調節」建議
```

也就是說:**庫存與成本是從券商流「進」方舟**,不是從方舟「抓」出來。方舟是計算工具,不是資料源。

> 這點直接影響專案規劃:若目標是「在 Google 雲端留一份庫存與成本紀錄」,正確的取得點是**券商**,不是方舟。從方舟反向讀資料只能靠截圖 OCR,不可靠。

### 3. 社群的自動化 = 用 AI 代替手指去點 APP

不是 API 串接,是 GUI 自動化。整條鏈是:

`Codex(桌面)` + `OpenClaw(俗稱「龍蝦」)或 Hermes Agent` + `Telegram Bot(手機遙控)` + `排程`

穩定性完全取決於 APP 介面沒改版、模擬器沒當、電腦沒休眠。社群裡回報的問題大多屬於這類(見後述)。

## 一、方舟運算 APP 介面結構

底部四個分頁:

| 分頁 | 功能 |
|---|---|
| **自選** | 「布局自選」清單;「調節庫存 → 編輯我的庫存股」可分台股 / 美股輸入持股 |
| **策略** | 提供「美股價值區」「ETF 價值區」「台股價值區」等選股清單,可整批加入自選 |
| **運算** | 輸入購買力(TWD / USD),算出今日結果為「布局」或「調節」 |

## 二、社群版每日更新流程(三階段)

### 階段一:更新布局自選

1. 自選 → 布局自選 → 右上角鉛筆 → 逐一移除舊標的,直到顯示 **0 檔**
2. 返回 → 策略 → 選「美股價值區」/「ETF 價值區」→ 右上角「＋」
3. **確認正好 10 檔且全部勾選;不是 10 檔就停止,不得加入錯誤清單**
4. 下一步 → 勾選市場(美股 / 台股)→ 右下角「確認」
5. 回布局自選確認已加入 10 檔

### 階段二:輸入購買力並運算

1. 運算 → 幣別切換 USD
2. 新台幣購買力輸入 0(除非另有金額)
3. 美元購買力**只能用「整股／定股(USD)」的下單可用金額**
   —— 不得使用銀行餘額、碎股、定額或其他欄位
4. 輸入前先清除舊數字,用 APP 畫面上的數字鍵盤輸入
5. 記錄今日結果是「布局」或「調節」及確切金額

### 階段三:更新庫存

1. 自選 → 調節庫存 → 鉛筆 → 編輯我的庫存股 → 切台股 / 美股
2. 逐檔核對:股票代號、總股數、成交均價
3. **總股數保留全部小數位**(54.17777 就輸入 54.17777,不得四捨五入)
4. **成交均價一律四捨五入至小數點後兩位**(584.936220 → 584.94)
5. 只儲存有變動的股票;數值相同的不要重複儲存
6. 券商有、方舟沒有的股票 → 用「新增持股」加入
7. **券商已無的股票不得自行刪除,要先回報**
8. **不得調整庫存排序、不得拖曳右側三條線圖示**

### 輸入時的坑(社群實測)

- 股票代號欄位若跳出中文輸入法 / 注音 / 候選字,要先清空並切回英文
- 數字之間要留短暫間隔,否則第一個數字會遺失
- 股數與均價一起改若儲存失敗,改成先存股數、再重開單獨存均價
- 偵測到使用者碰過模擬器,要重新截圖取得畫面,不得沿用舊座標

## 三、社群回報的常見故障

| 症狀 | 社群解法 |
|---|---|
| 手機收不到回應 | 電腦關機或休眠了。要關閉休眠模式並維持連線 |
| 排程有跑但庫存沒更新 | 券商 APP 無法自動登入,需維持登入狀態 |
| 更新到錯誤的帳號 | 有多帳號時必須在指令中指定帳號,「越細節越好」 |
| 連線不穩定 | 檢查分享器 DNS,改用 Google 或中華電信的 DNS |
| Telegram 收不到驗證碼 | 移除 Who's Call 後重裝 Telegram |
| 模型額度用盡 | 免費額度不足以完成安裝,社群普遍建議訂閱付費方案 |

## 四、對本專案的評估

### 可以自動化、且不必依賴方舟的部分

| 項目 | 做法 | 狀態 |
|---|---|---|
| 台股每日收盤價 | TWSE / TPEx 官方 OpenAPI | **已完成** `scripts/fetch_prices.py` |
| 月營收與創新高篩選 | TWSE OpenAPI `t187ap05_L` | 待辦 |
| 庫存與成本的雲端紀錄 | `data/holdings/` csv 快照,累積歷史 | 骨架已建 |
| 持股市值 / 損益報表 | 庫存 csv × 收盤價 csv | **已完成** `scripts/make_report.py` |

### 只能靠 GUI 自動化的部分

**把庫存寫回方舟運算 APP** —— 沒有替代路徑,只能模擬器 + Computer Use 點畫面。

### 風險提醒(若之後要做 GUI 自動化)

1. **社群指令裡包含「每日清空布局自選」**。授權 AI 執行刪除動作,一旦介面改版或判讀錯誤,可能刪到不該刪的東西。社群自己也發生過「更新到另一個帳號的庫存」。
2. **GUI 自動化沒有交易語意保護**。它只是在點畫面,不知道自己點的是什麼,錯了不會有 API 那樣的錯誤回傳。
3. **建議做法**:先讓程式產出「應更新清單」(哪幾檔要改、改成什麼),人工核對後再執行寫入;不要一開始就全自動無人值守。
4. 方舟只產生**建議**,買賣決策與下單一律由本人執行。社群中也有教練明確說明工具只給建議、修剪要自己來。

### 這份文件不採用的內容

社群對話中有一段給 AI 的提示詞,要求「跳過所有互動選單提問、暴力寫入設定檔、背景啟動服務」。這種免確認的自動安裝方式風險偏高(設定檔被覆蓋、服務在背景無聲執行),本專案不採用。需要安裝任何工具時,一步一步確認。
